# 鹈鹕骑自行车（Pelican Bike Ride）

一个纯 SVG 手绘的 2D 循环动画：一只戴护目镜、系红围巾的鹈鹕骑着复古自行车穿过乡村。整幅画面由内联 SVG 绘制，动画由 CSS 与一段 JavaScript 共同驱动，无任何外部依赖。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `pelican-bike.html` | 主文件。内联 SVG + CSS + JS，直接打开即可播放 |
| `pelican-bike-demo.webm` | 录制的演示视频，11.2 秒，1280x720，25fps（VP8） |

## 快速开始

用现代浏览器（Chrome / Edge / Firefox / Safari）直接打开 `pelican-bike.html` 即可观看，不需要本地服务器，也不需要联网。

## 动画内容

- 车轮辐条、牙盘、曲柄匀速旋转，与踩踏节奏同步
- 双腿用二骨反向运动学驱动：两只脚严格锁在踏板圆周上，膝盖随曲柄自然收展
- 躯干绕髋关节小幅左右摆动，模拟骑行时的重心晃动
- 大喉囊前后摆动并带轻微抖动，红围巾迎风飘动
- 前翼按住车把，后翼和尾羽轻轻扑动
- 多层视差背景：太阳光芒、漂移的云、远山与风车、树线、滚动路面
- 路面细节还原旅行感：车道箭头、水洼、路锥、鱼形警告牌、路边灌木与野花
- 车尾扬尘和地面阴影增强速度感

## 技术实现

### 图形

- 全部为 `<svg>` 内联矢量元素，`viewBox="0 0 1200 675"`
- 远近分层绘制在天与地的顺序：天空 → 太阳/云 → 远山 → 树线 → 路面 → 车与鹈鹕
- 背景平铺瓦片写在 `<defs>` 中，用 `<use>` 复制两份后做无缝横向滚动

### 动画

| 技术 | 用途 |
| --- | --- |
| CSS keyframes | 视差滚动、云朵漂移、太阳光线旋转、风车叶片、车尾扬尘 |
| JS rAF 时间轴 | 单一时钟同步驱动轮子、曲柄、踏板、双脚、双腿、躯干、喉囊、围巾和翅膀 |
| 二骨反向运动学 | `髋 → 膝 → 脚` 的三点构型，取膝朝前（x 较大）的一组解，保证脚点永不离开踏板 |

### 关键参数

参数集中在 `<script>` 顶部的常量里，改数值即可调整形态或节奏：

| 常量 | 含义 | 默认值 |
| --- | --- | --- |
| `OMG` | 踩踏角速度（rad/s） | `2.15` |
| `O` | 中轴（五通）坐标 | `{ x: 602, y: 483 }` |
| `HIP` | 髋关节坐标 | `{ x: 577, y: 344 }` |
| `R` | 曲柄半径（px） | `30` |
| `Lt` | 大腿长度（px） | `86` |
| `Ls` | 小腿长度（px） | `90` |

路面滚动周期（`6.6s`）与车轮线速度按同一速度标定，视觉上车轮与地面不会明显打滑。

## 演示视频

`pelican-bike-demo.webm` 通过 Playwright + 无头 Chromium 录制：

- 注入真实时钟替换 `requestAnimationFrame`，避免无头模式下 rAF 节流导致画面卡顿或变速
- 1280x720，25fps，时长 11.2 秒
- 已裁掉开头约 1.3 秒的空白帧
- 所用 ffmpeg 仅带 VP8 编码器，因此输出为 WebM 而非 MP4；Chrome / Edge 可直接播放

## 兼容性

- 现代 Chromium / Firefox / Safari 均可运行
- 纯 `file://` 打开即可，无需构建与服务器
- 页面滚动条、缩放和深色背景样式在移动端与桌面端都是自适应的
